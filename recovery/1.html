CogniSpike Guide

What are Spiking Neural Networks (SNNs)?

SNNs are a type of neural network inspired by the brain. Unlike traditional networks that use continuous values, SNNs communicate using discrete "spikes" or pulses, similar to biological neurons. This makes them potentially more power-efficient and better suited for processing information that changes over time.

What is Spike Encoding?

Since SNNs understand spikes, not pixel values, we need to convert standard data (like images) into spike patterns. This translation process is called spike encoding. This dashboard uses "Rate Encoding," where brighter pixels fire more spikes over a short time window.

About CogniSpike

This dashboard demonstrates SNN principles. You can classify handwritten digits, visualize how images are encoded into spikes (raster plot), or see an animation of the encoding process (live encode).
